# Approach Three — five root-movement rules (teaching distillate)

Source: *Barbershop Arranging Manual* (1980) printed pp. 206–243 ≈ OCR `p219`–`p256`.  
**Copyright:** original paraphrase + worked Roman-numeral drills — not long verbatim quotes.

Use this chapter to **rank and coach** chord candidates between pillars, and to teach *why* a move is strong. The engine **soft-ranks** weak moves (low score / no rule tag) rather than hard-rejecting every non-classic option.

**Circle intuition first:** [21-circle-of-fifths.md](21-circle-of-fifths.md). This file is the **source of truth for R1–R5 ranking / coaching**.

---

## Core idea

Every stretch of melody aims at a **harmonic pillar** (target / goal). Ask: *where is the harmony going?*  
Chords between pillars must keep the **harmonic highway** intact. Melody notes must be chord tones (1, 3, 5, 6, 7, or 9) of a barbershop-vocabulary chord.

Except for root-position **tonic**, almost everything else exists to **move music forward**.

---

## Springboard axiom (I / IV)

**Tonic (I) and subdominant (IV) may leap to any vocabulary root.** After the leap, normal Rules 1–5 resume until the next pillar.

| Key of C | Springboard roots | After leap |
| --- | --- | --- |
| I | C (any PCF quality) | Next move must obey R1–R5 toward a pillar |
| IV | F | Same |

Cadential **IV → I** (P5 up) is the main *progressive* use of up-a-fifth; most other up-fifths are **retrogression** (backup on the circle).

## Rule statements (modern English)

> **First read:** master **R1 + springboard** (and skim R3 melody gate). Defer deep R2/R4/R5 until after you finish [19](19-melody-to-arrangement.md).

### R1 — Perfect fifth

A target may be approached by a chord rooted a **perfect fifth above** (most common / strongest) or a **perfect fifth below**.

- **Down a P5** (up P4) = strongest progression; long descending-fifth chains are idiomatic.  
  Full map + arranging recipe: [21-circle-of-fifths.md](21-circle-of-fifths.md).
- **Up a P5** as true progression ≈ **IV → I** cadence.
- Other up-P5 moves = **retrogression** (variety / out-of-chord melody), then resume forward motion.
- Prefer diatonic roots of the song’s key for long chains.

### R2 — Chromatic half step

A target may be approached by a chord rooted a **½-step above or below**.  
Usually limited to **barbershop 7ths** (occasionally 9ths). Dim7 chromatic motion is under R4.

### R3 — Tritone counterparts

Chords (usually BS7 / 9) rooted a **tritone apart** resolve to the **same** targets and are **counterparts** (family members).

- Sequential swap of counterparts = **family substitution / holding pattern**, *not* progression — progression happens when the shared target arrives.
- 3rd of one BS7 = 7th of the other (and vice versa).
- **Melody gate** for optional counterpart use: lead is the **3rd, 7th, raised root, or lowered 5th** of the chord you’re on (or of the implied surrounding harmony).

### R4 — Diminished seventh

Dim7 may (1) **effect progression**, (2) **anticipate** a coming harmony, or (3) **hold** (variety / color / rhythmic motion).

- Dual-root: ±½-step and P5 motion happen *together* (tritone pairs inside the chord).
- Only **three** distinct dim7 PC-sets; any tone may act as “root” by function.
- Prefer not chaining two dim7s; follow with BS7/9, Major, or occasionally minor.
- Holding uses: melody as **raised root / ♭2 / ♭9**, **lowered 3rd**, **lowered 5th**, or **dim7 interval (6th / 13th)** of the implied harmony.
- Anticipate: dim7 that **contains the root of the next chord**, without stealing its arrival.

### R5 — Major third up from a BS7

A **barbershop 7th** may progress to a chord rooted a **major third above**, typically when the **target has no 7th**.  
Classic: **♭VI7 → I**. Also seen: ♭III7 → V (same voice-leading idea).  
Do not confuse with a *holding* move that only *passes through* a M3-related root on the way to a different shared target (that’s R3-family logic, not R5 progression).

## Family circle (adjacent approaches to a pillar)

For any pillar **T**, legal immediate approaches (melody permitting) come from the **adjacent counterpart families**:

| Approach type | Roots relative to T (semitones) | Example T = C |
| --- | --- | --- |
| P5 above (R1) | T+7 | G → C |
| P5 below (R1) | T+5 | F → C |
| ½ above (R2) | T+1 | D♭/C♯ → C |
| ½ below (R2) | T−1 | B → C |
| Counterpart of those (R3) | tritone of each | D♭↔G, F↔B, etc. as family pairs |
| Dim7 (R4) | dual-root from set containing motion to T | e.g. B°7 / F°7 family toward C |
| BS7 a M3 below (R5) | T−4 | A♭7 → C (no 7th on C) |

**Retrogression limit:** except leaps from I/IV, usually back up **only one family group**.

Chromatic BS7 chains sound “right” because every other chord is a **counterpart substitute** for a pure Circle-of-Fifths chain.

## Worked root sequences — key of C (transpose of manual drills)

Roman numerals relative to **C major** unless noted. Roots shown as letter + quality when the manual stresses BS7 color.

### R1 — descending fifths (idiomatic highway)

From *Five Foot Two*–style chain (manual Ex. 1, key of C):

```
I → III7 → VI7 → II7 → V7 → I
C → E7 → A7 → D7 → G7 → C
```

From *If I Had My Way*–style (manual Ex. 2):

```
I → VI7 → II7 → V7 → I → VI7 → II7 → …
C → A7 → D7 → G7 → C → A7 → D7 → …
```

Cadential up-fifth only:

```
IV7 → I
F7 → C
```

Retrogression (backup one notch), then resume:

```
… → V7 → II7 → V7 → I   (II7 is backup from V, then forward again)
… → G7 → D7 → G7 → C
```

### R2 — chromatic BS7

Half step **down** into target:

```
… → D7 → D♭7 → C   or   … → E7 → E♭7 → …
```

Half step **up** into target:

```
… → B7 → C   or   … → A7 → B♭7 → …
```

Manual insight: a long chromatic string like  
`A♭7–G7–G♭7–F7–E7–E♭7`  
is aurally a Circle-of-Fifths chain with counterparts inserted  
(`D7→G7→C7→F7→B♭7→E♭7` with A♭/G♭/E as family substitutes).

### R3 — counterpart pairs and shared targets (X = C world)

Counterpart pair **E♭7 ↔ A7** (tritone). Both move to the same places:

| From | P5↓ | P5↑ | ½↑ | ½↓ |
| --- | --- | --- | --- | --- |
| E♭7 | A♭ | B♭ | E | D |
| A7 | D | E | B♭ | A♭ |

Holding (no progression): `E♭7 → A7` (or reverse), then progress when `B♭` (or other shared target) arrives.

Teaching progression into **I = C**:

```
Counterpart pair of V:  G7 ↔ D♭7
Both resolve toward C by complementary R1/R2 moves.
Holding: G7 → D♭7 → G7 … then → C
```

Into **IV = F**:

```
C7 ↔ G♭7   (both aim at F / etc.)
```

### Melody pitch-class gates for counterpart (R3)

When sitting on a BS7 with root **R**, counterpart root = **R+6**. Swap is especially useful when lead PC is:

| Lead role on current chord | PC relative to R | Example on G7 (→ toward C) | Counterpart D♭7 contains |
| --- | --- | --- | --- |
| 3rd | R+4 | B | = 7th of D♭7 |
| 7th | R+10 | F | = 3rd of D♭7 |
| Raised root (♯1 / ♭2 of chord) | R+1 | A♭ | = 5th of D♭7 |
| Lowered 5th of surrounding harmony | (surround root)+6 | Melody G under D♭ harmony → G7 | G is root of counterpart |

**Weak / usually no without those tones:** swapping counterparts when the lead is only chord-root or plain 5th of the *current* BS7 usually fails the free-swap case (manual classic free swap = 3rd or 7th; raised root / lowered 5th also open the gate).

Worked legality (pillar C, current V7 = G7):

| Melody PC | Role on G7 | Counterpart D♭7 OK? |
| --- | --- | --- |
| B | 3 | yes (↔7 of D♭7) |
| F | ♭7 | yes (↔3 of D♭7) |
| A♭ | ♯1 / ♭9 of G | yes (5 of D♭7) |
| D | 5 | weak / usually no for free swap |
| G | 1 | weak / usually no |

### R4 — Dim7 examples (C-major context)

Three families:

| Family | PCs | Spellings often seen |
| --- | --- | --- |
| {0,3,6,9} | C°7 / E♭°7 / G♭°7 / A°7 | |
| {1,4,7,10} | C♯°7 / E°7 / G°7 / B♭°7 | |
| {2,5,8,11} | D°7 / F°7 / A♭°7 / B°7 | |

**Progression (dual root):** e.g. toward D minor / G:

```
E♭°7 → Dm7 → G …     (½↓ = also A°7 → D as P5↓)
```

**Anticipate:** dim7 containing next root precedes that chord  
(e.g. F°7 → F7 — “doesn’t steal the thunder”).

**Hold under implied harmony:**  
melody as ♭3 / ♭5 / dim7(6) of implied chord → same dim7 family as holding color.

**Raised root of a BS7 → dim7:** raise the root of any BS7 → dim7; lower any dim7 tone → BS7 on that tone.

Teaching swipe into V7 of C — analogue of manual Ex. 38 (Bb → E°7 → F7 → Bb), where dim7 sits a ½-step below V7 (dual-root with P5↓ into V):

```
C → F♯°7 → G7 → C     (½ below V7; dual-root also reads as C°7 → G via P5↓)
C → C°7 → G7 → C     (holding / color under tonic span before V, if melody allows)
```
### R5 — M3 above from BS7 (target without 7th)

Key of C:

```
♭VI7 → I
A♭7 → C
```

Also (manual flavor): BS7 on ♭3 → V:

```
♭III7 → V
E♭7 → G
```

Voice leading: root and 7th of the BS7 resolve **outward by ½ steps**, often yielding **second inversion** of the target with doubled 5th.

Not R5 when Bb7 → D7 is only a *pass* toward Eb (shared target) — that is family/holding, not M3 progression (manual Ex. 28 clarification).

## One minor-target example (from manual)

Dim7 into **E minor** (manual Ex. 20):

```
D♯°7 → Em     (½↑)
A°7  → Em     (same PC-set as dual root, P5↓)
```

In C major this is a side trip to **iii**; same dual-root logic applies to any minor pillar.

Minor side-highway (manual *Sing Out* analysis, Bb key → transposed to C):

```
I  →  V7/vi → vi → … → V7/ii → II7 → …
C  →  E7    → Am → … → A7    → D7  → …
```

Leap onto the secondary dominant is legal from **I** (springboard).

## Common mistakes called out in the manual

1. **Over-engineering simple songs** — exotic legal options that sound “artificial” (Tell Me Why options). Prefer simple, singable, lyric-serving choices.
2. **Too quick at tempo** — counterpart flicker, dense dim7 swaps, or rapid SCF neighbors that are legal on paper but fail at up-tempo (counterpart caution; pick-up over-harmonization).
3. **Static pillars** — sitting on the same triad for multiple bars when lyric/melody want motion (use BS7 / counterpart / dim7 *on strong beats*).
4. **Introducing the 7th too soon** — once a functional 7th appears, sustain it until the next harmony (fleeting 7ths become passing tones, not BS7 function).
5. **Wrong harmonic rhythm** — return to the pillar on a **weak** beat; change harmony off the strong/syncopated accent the melody implies.
6. **Treating family swap as progression** — E♭7→A7 does not progress; progress is when Bb (shared target) arrives.
7. **Root motion by 3rds or diatonic steps as primary highway** — not typical barbershop between pillars (sheet music may show it; ear often prefers circle logic).
8. **Chaining dim7 → dim7** — rare; hard to tune; prefer dim7 → BS7/Major/minor.
9. **Retrogression too far** — backing up more than one family group (except from I/IV leaps).
10. **R5 when target has a 7th** — classic R5 wants a **non-seventh** target; using M3-up into a 7th chord is a different function.
11. **Voicing vs VL fights** — “best” chord spelling vs nearest-note voice leading; avoid doubling the 3rd from lazy tenor resolution.
12. **Forcing SCF on the pillar root** — rarely harmonize the *root* of primary harmony with SCF; keep primary clear on strong beats.
13. **Climax vs lyric** — stuffing rich SCF at a soft lyric; Step IX: density should match words.
14. **Ignoring springboard discipline** — leaping from II or V as if they were free springboards.

## Candidate ranking sketch (engine)

The product **ranks** candidates with Approach Three motion scores; weak options still appear with low scores (coach, not a hard filter).

```
score(prev, next, towardPillar):
  +w1 if Rule1 P5-down toward pillar
  +w2 if Rule2 chromatic BS7 connect
  +w3 if Rule3 counterpart holding (melody gate OK)
  +w4 if Rule4 dim7 escape/coaching helpers
  +w5 if Rule5 M3-up BS7 into non-7th target (−soft if target is also 7/9)
  +bonus if next.root == pillar
  +bonus if springboard (prev is I or IV)
  −penalty minor-second voicing / out of range / “too quick” at tempo
```

**Engine coverage note:** R4 dual-root *motion classification* is teaching-only; code ships dim7→BS7 / dim7→m6 escape helpers plus chain/flicker lints.
