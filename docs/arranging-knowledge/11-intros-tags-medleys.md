# Intros, tags, medleys, and key lifts

Source: BAM pp. 342–390.  
**Goal:** Frame the chorus and manage key without wrecking form.

---

## Intros

### When you need one

| Need intro | Skip intro |
| --- | --- |
| Chorus assumes a mood already set | Opening lyric already sets the scene |
| First harmony isn’t tonic (intonation risk) | Verse exists and does the job |
| Show opener / medley setup | Song is famous from bar 1 |

### Jobs

Announce theme/title · set mood · establish key · hello · disguise a famous tune.

### Sketch (C)

4-bar intro ending on **V7** into the chorus:

```
| C   | Am  | D7  | G7 ||  → chorus on C
| I   | vi  | II7 | V7 ||
```

---

## Tags

### Purpose

Exclamation point / lyrical postscript — not a second chorus.

### Approach

Song cadences on **I**. Tags rarely *start* on I — prefer **IV** or **II/II7** (sometimes VI). Fill I→tag with a **swipe**.

Common setups:

| From song I | Into tag |
| --- | --- |
| Swipe via VI7 | II-type tag |
| I7 | IV tag |
| III7 | VI or IV |

### Form

Even lengths (2, 4, 6, 8… — not odd). Match song phrase length and cadence placement. Prefer circle-of-fifths motion; keep a melodic focus.

### Pedagogical entry (C)

```
Song end:  C
Swipe:     C → A7 → D7
Tag open:  D7  or  F …
Cadence:   … G7 → C
```

---

## Key lifts / changes

### Practices

| Prefer | Avoid |
| --- | --- |
| Up **½ step**, **whole step**, or **m3** | Random distant jumps mid-phrase |
| At **section boundaries** | Mid-phrase hitch that breaks lyric |
| New key’s **V7** in lead+bass on stable tones | Lead stuck on the new V’s ♭7 |
| Preserve measure count | Chopping bars to “fit” the lift |

### Pedagogical lifts from C

| Destination | Interval | Classic plant |
| --- | --- | --- |
| D♭ | +1 | C7 color → A♭7 → D♭ |
| D | +2 | C7 → A7 → D |
| F | +5 (up 4th) | **C7 → F** (old I7 = new V7) |
| E | +4 | Tertian / connector BS7 → B7 → E |

Abrupt **hitch** (slam to new I with no common tones) is common in practice — teach it, don’t default to it.

App helpers: `suggestKeyChanges` / hybrids / `I7-as-V` template ([docs theory plan](../docs/theory-correctness-remediation-plan.md)).

---

## Medleys

- Unified **theme/lyric idea** across ≥2 songs — not “full song + 8 bars tacked on.”  
- Shapes: back-to-back + intro/tag; intro–song–interlude–song–tag; return of song 1.  
- **Key lifts toward the end** for climax; change keys for range fit.  
- Contest: tight unity + permissions; show medleys freer.

---

## Checklist

1. Intro ends ready for chorus tonic (usually via V7).  
2. Tag length even; starts off-I; swipe bridge from song cadence.  
3. Key change between phrases; form length preserved.  
4. Medley theme clear in one sentence.
