# Embellishments — beyond the block chart

Source: BAM pp. 297–331.  
**Goal:** Add interest **after** pillars, PCF/SCF, and voicing work — without breaking form ([10](10-song-selection-form.md) F-rules).

---

## Principle

Harmonization alone is a **chart**. Embellishments make an **arrangement**.  
Never use a device only as decoration: it should set mood, fill dead air, underline lyric, prepare a key change, or create climax.

---

## Device catalog (highlights)

| Device | What it is | How-to gist |
| --- | --- | --- |
| **Backtime** | Lead keeps full lyric; others omit/hold | Spotlight melody |
| **Bell chord** | Voices enter one at a time | Build a chord in time |
| **Blossom** | Unison → contrary out to 4 parts | Intro / soft openers |
| **Cascade** | Top-down chord build | Invert a pyramid |
| **Contrary swipe** | Two parts move opposite; others sustain | Keep consonant |
| **Echo** | Repeat a fragment | **Most abused** — use sparingly |
| **Key change** | New tonic | See [11](11-intros-tags-medleys.md) |
| **Lead-in** | Pickup into a phrase | Often + key lift + patter |
| **Patter** | Rhythmic chatter vs straight melody | Any voice(s) |
| **Pedal** | Sustained tone under moving harmony | Often lead holds |
| **Pyramid** | Build from unison upward | Great in intros |
| **Swipe** | Harmony moves under held (or natural) lead | See below |
| **Tag / intro / interlude** | Structural frames | [11](11-intros-tags-medleys.md) |

Also: fade endings, glissandi, lyric effects, overlapping phrases, meter changes, melody transfer, hanging voice, spoken lines — all optional and easy to overuse.

---

## Swipes (core skill)

### Jobs

1. Fill cadence space (no piano).  
2. Prepare the next phrase or key change.  
3. Underline a lyric.  
4. Pure excitement — still must fit the meter.

### Where

Usually **phrase endings** / sustained cadence notes — not mid-word chaos.

### Shapes

- Simple progression under a held lead.  
- Inversions of one chord.  
- Excursion that returns to the start chord.  
- Lead pedal while others walk the circle.

Favorite move: **V7 → something → I** (often via VII7 / counterpart color).

### Lead behavior

Traditionally **holds the melody pitch** while others move. Lead may move if natural — don’t load lead with awkward harmony tones just to “make the swipe.”

### Pedagogical C swipe (lead holds C)

```
Chord:  C7      B♭7     C
Tenor:  B♭4  →  A♭4  →  G4
Lead:   C5   →  C5   →  C5     ← held
Bari:   E4   →  D4   →  E4
Bass:   C3   →  B♭2  →  C3
```

### Form rule

Fit the meter. If singers rush or you add a beat, the swipe failed.

---

## Order of work

1. Finish Approach Two through solid voicing.  
2. Mark cadence holds that feel empty.  
3. Add **one** swipe family per section; listen.  
4. Only then consider echo / patter / bells.
