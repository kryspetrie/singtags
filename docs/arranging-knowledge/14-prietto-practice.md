# Prietto practice — strong voicing, Dom9, QA, SAI vs BHS

Source: Carole Prietto, *Arranging Barbershop Harmony* (2nd ed.).  
**Goal:** Turn theory into a repeatable arranging/QA habit.

## Style building blocks (align to [01](01-style-definition.md))

Four parts · melody in lead · unaccompanied · consonance · lock & ring · **tritones in BS7/9** resolving into major · circle-of-fifths motion · creative devices (swipe, echo, backtime, patter).

Remember the **primary** naming trap: theory I/IV/V ≠ SAI “primary chords” (major / BS7 / BS9).

## Strong voicing cheat sheet

| Chord | Strong bass | Completeness |
| --- | --- | --- |
| Major | Root; root doubled | Don’t double major 3rd |
| Minor | Root if pillar; 3rd if “sub 6” color | Flexible doubles |
| BS7 / m7 | Root **or** 5th | All four tones |
| Maj7 / add9 / M6 / m6 | Root | All four |
| Dom9 | Omit root → bass **5**; omit 5 → bass **1** | Keep 3, ♭7, 9 |
| Dim7 | Context (any PC can act as root) | All four; ear picks bass |
| Aug | Any (prefer lowest) | Last resort |

**Lead wins collisions:** if lead has the root, bass takes the 5th.

### Worked Co5 fragment in C (“Five Foot Two” type)

Pillars/chain: **C | E7 | A7 | D7 | G7 | C**

1. **C major:** bass C; double C somewhere; lead/bari trade E/G.  
2. **E7** (E G♯ B D): if lead sits on E, bass often on **B** (5th).  
3. **A7 / D7 / G7:** flip bass root↔5th opposite the lead when lead occupies root or 5th.  
4. Non-chord melody tone → try Dom9-omit-root / m6 spelling in context.

## Dom9 practice vignette

Melody note outside an F7 pillar plugs into **C–E♭–G–A**:

- As **Cm6**, or  
- As **F9 omit root**,

depending on whether you are approaching/leaving F7. Same PCs; different story.

## QA checklist (automate what you can)

### Arrangement

1. Key fits average **lead** range (TTBB vs SSAA presets).  
2. Chords match **implied harmony** / confirmed pillars.  
3. Triads correctly doubled; four-note chords complete.  
4. Embellishments still legal & complete.  
5. Homorhythmic default; extras intentional.  
6. Breaths planned.  
7. Ear test: nothing ugly sticks out.

### Manuscript

Title/credits/copyright · page/measure numbers · lyric placement · spacing.

### Human gates

Story/lyric devices · Song Assessment (SAI) · copyright/licensing.

App: lints for illegal nature, incomplete triad, thin ninth, doubled third, BS7 density, tenor/lead order, etc.

## SAI vs BHS (profiles)

| Topic | SAI (`sai11`) | BHS (`bhs_extended`) |
| --- | --- | --- |
| Chord vocab | Strict **11** | 11 + dim / half-dim (+ rarer) |
| Homorhythm | Tighter | More leeway |
| Time limit | ~7 min singing (typical) | None / different |
| Form | Stronger Tin Pan Alley chorus norms | More flexible + theme |
| OOV chords | No | Rare OK if musical — don’t auto-suggest |

## Practical tips

- Don’t arrange your forever-favorite as the *first* project; arrange for real ranges.  
- Tags proportional; optional Co5 tag skeleton: I → III7/VI7 → chain home.  
- Intro: start near tonic; end V7 into chorus; 4-bar phrases.  
- Pop tunes: keep BS voicing (bass R/5) even when Co5 is sparse — don’t force BS7s that trash the song.  
- Use original sheet music for true lyrics/harmony; lead sheet before deep voicing.
