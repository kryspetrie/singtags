# Harmonic rhythm — pillars vs decoration

Source: BAM pp. 67–72 (OCR ~p80–p85).  
**Goal:** Keep the song’s identity by placing **required root changes** on time.

---

## Definitions

| Term | Meaning |
| --- | --- |
| **Harmonic rhythm (HR)** | How often the **harmony root** changes relative to the beat — not how busy the melody is |
| **Primary pillars** | Root changes the melody **implies** — required signposts |
| **Embellishing chords** | Extra chords between pillars — optional color that must not shove pillars off the clock |

If you omit or delay a required pillar to insert a clever passing chord, you have rewritten the song.

---

## Tempo vs harmonic rhythm

| Song type | Typical HR | Why |
| --- | --- | --- |
| Uptempo / patter | Often **slower** HR (one root over many bars) | Singers need time |
| Ballad | Often **faster** HR (changes inside a bar) | Emotional motion |
| Extremely static HR | Weak for barbershop | Nowhere for BS7 highways |

Accelerating HR into a cadence increases intensity.

---

## Where pillars land

Prefer changes on **strong beats**:

| Meter | Strong beats |
| --- | --- |
| 4/4 | 1 and 3 |
| 3/4 or 2/4 | Downbeat |

If a change is forced onto a weak beat, **recover** on the next strong beat. Syncopated melodies: move harmony **with** the displaced accent.

---

## Worked 8-bar ballad phrase (C major)

Melody implies tonic–subdominant–dominant–tonic. Pillars on strong beats:

```
Bar:  1    2    3    4    5    6    7         8
Root: C    C    F    C    C    F    D7  G7    C
RN:   I    I    IV   I    I    IV   II7 V7    I
Beat: 1         1         1         1   3     1
```

**Legal embellishment** (bar 6→7): insert A7 as VI7 before D7:

```
… F | A7 D7 G7 | C
… IV | VI7 II7 V7 | I
```

Pillars F, then the II7–V7–I cadence, stay on schedule.

**Illegal “cleverness”:** replace bar 3’s F with a long E7 that never returns to F/C on the strong beat the song needs — listeners lose the form.

---

## Circle preference for pillars

Primary roots that already suggest **descending fifths** arrange more easily:

| Friendly pillar sketch | Awkward pillar sketch |
| --- | --- |
| C → F → G → C | C → D → E → F (rising steps as *basics*) |
| C → A → D → G → C | Long static C for 8 bars |

Approach Two still **asks your ear** first; sheet-music symbols are assists, not law.

## Minor-feel sketch (A minor)

```
| Am | Am | Dm | Am | Am | Dm | Bø7 E7 | Am |
| i  | i  | iv | i  | i  | iv | iiø  V7 | i  |
```

Barbershop still prefers **major-ish V7** (E7 with G♯) into i.

---

## Arranger checklist

1. Sing the melody alone — tap where harmony *must* change.  
2. Mark those roots as pillars (confirm in the app).  
3. Only then add passing BS7s / SCF color.  
4. Re-sing: do the pillars still hit the same beats?
