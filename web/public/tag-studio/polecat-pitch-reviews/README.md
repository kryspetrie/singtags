# Polecat pitch → Tag Studio (retired)

Automatic pitch→Tag Studio projects (`pitch_studio.json` and the former gold
`seed-polecat-pitch-*` seeds) are **retired**. Detected pitches were not
trustworthy enough for one-click import or Coach seed publishing without
manual validation.

`index.json` is intentionally empty so Tag Studio list refresh removes any
leftover `seed-polecat-pitch-*` auto-seeds from device libraries.

`pitch_stacks.json` timeline extracts may still be used for arranging research;
they are not published as Tag Studio projects from the Tag page.
